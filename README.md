# Файлы для итогового задания

В директории `tests` находятся тесты для проверки API, которое должно быть реализовано в веб-сервере.

Директория `web` содержит файлы фронтенда.

# Описание проекта
    Веб-сервер, который реализует функциональность простейшего планировщика задач. 

# Список выполенных заданий со звёздочкой
    * Реализована возможность определять порт при запуске сервера. Если существует переменная окружения TODO_PORT, сервер при старте слушает порт со значением этой переменной. 
    * Реализована возможность определять путь к файлу базы данных через переменную окружения. Для этого сервер получает значение переменной окружения TODO_DBFILE и использовать его в качестве пути к базе данных, если это не пустая строка.
    * Реализованы правила повторения задач по дням, неделям и месяцам.
    * Добавлена возможность выбрать задачи через строку поиска или на конкретную дату. 

# Инструкция по запуску кода локально
    * на локальном компьютере зайдите в директорию, где будет проект, и в терминале (консоли) выполните команду:
        git clone https://github.com/maxim-buluchevskiy/go_final_project.git 
    * Задайте необходимые переменные в файле variable.env и запустите сервер
         go run main.go
    * Параметры по умолчанию файла variable.env
        TODO_PORT = 7540
        TODO_DBFILE = "./go_final_project/database/scheduler.db"
    * URL сервера  http://localhost:7540/

# Инструкция по запуску тестов
    * Необходимые параметры в файле tests/settings.go:
        Port = 7540
        DBFile = "./go_final_project/database/scheduler.db"
        FullNextDate = true
        Search = true
        Token = ``
    * Запуск тестов командой  go test ./tests

# Инструкция по сборке и запуску проекта через докер
    * Создайте Docker-образ:
        docker build -t go-final-project
    * Запустите контейнер:
        docker run -d -p 7540:7540 -v $(pwd)/database/scheduler.db:/app/scheduler.db go-final-project
    * Проверьте работу приложения:
        http://localhost:7540/
